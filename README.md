[Helion](https://github.com/pytorch/helion) is a Python-embedded domain-specific language (DSL) for authoring machine learning kernels, designed to compile down to [Triton](https://github.com/triton-lang/triton), a performant backend for programming GPUs and other devices. Helion aims to raise the level of abstraction compared to Triton, making it easier to write correct and efficient kernels while enabling more automation in the autotuning process.
